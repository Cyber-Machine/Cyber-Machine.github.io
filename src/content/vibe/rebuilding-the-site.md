## Rebuilding the site

I wanted the site to stop feeling like a frozen student portfolio and start acting more like a personal publication.

The main constraint is maintenance. If updating the site feels annoying, the site dies.

So the current direction is:

- lighter content management
- fewer moving parts
- stronger writing and project structure
- a place for short notes that do not need to become full posts
